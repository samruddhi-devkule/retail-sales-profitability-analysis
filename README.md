# Retail Sales & Profitability Analysis

## 📊 Project Overview

This project analyzes retail sales data to identify sales and profitability trends across products, categories, and regions.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- SQL
- Microsoft Excel

## 🔍 Analysis Performed

- Analyzed sales and profit performance
- Compared product and category performance
- Examined regional sales trends
- Created KPI indicators
- Cleaned and transformed data using Power Query
- Created analytical measures using DAX
- Developed an interactive Power BI dashboard

## 📈 Dashboard

The dashboard includes:

- Total Sales
- Total Profit
- Sales Trends
- Category Performance
- Regional Analysis
- Product-level Analysis

## 💡 Skills Demonstrated

Power Query | DAX | Data Cleaning | Data Modeling | Data Visualization | KPI Analysis | SQL
